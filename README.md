# Program Data Mahasiswa Java

### Deskripsi

Program Data Mahasiswa adalah aplikasi sederhana berbasis Command Line Interface (CLI) menggunakan bahasa pemrograman Java untuk memasukkan dan menampilkan data mahasiswa serta menentukan status kelulusan berdasarkan nilai.

### Fitur

* Menambah data mahasiswa.
* Menampilkan data mahasiswa.
* Menentukan status kelulusan.

### Teknologi

Java dan JDK.
